# Button
Tres jerarquías de acción: primaria (IA, violeta cuántico), cristal (secundaria sobre fondos oscuros) y fantasma (terciaria).

- `nm-btn nm-btn--primary` — una sola por vista. Fondo `quantum`, texto blanco; en hover gana `glow-quantum`.
- `nm-btn nm-btn--glass` — acciones de consulta (ver fuente, exportar). Fondo `glass` con `blur-glass`; en hover borde `cyber` + `glow-cyber`.
- `nm-btn nm-btn--ghost` — omitir, cancelar. Texto `quantum-soft`.
- Foco de teclado: anillo de 2px en `cyber`, siempre visible.
- Verbos en infinitivo y ≤4 palabras: "Generar ruta", "Ver fuente", "Repasar ahora".
